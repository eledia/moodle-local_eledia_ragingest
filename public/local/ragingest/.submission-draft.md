## Short description

Opt-in Moodle course-content ingestion for external RAG services, with searchable course selection, status tracking, and reindex tools.

## Long description

eLeDia.ai RagIngest is a Moodle local plugin that extracts selected course
content and sends it to an external Retrieval-Augmented Generation ingestion
service. It is designed for controlled opt-in indexing: no course is sent unless
it is released through a pilot-course list, a category allow-list, or a
course-level override.

The plugin provides searchable multi-select settings for pilot courses and
course categories, a lock for pilot phases where only central admin settings
should decide, and a visible status panel for released courses that still need
indexing. Admins can queue all pending released courses or manually reindex a
single course by Moodle course ID.

Extraction logic is implemented through `ragingestextractor_*` subplugins. The
plugin ships extractors for common Moodle activity types including assignments,
books, databases, feedbacks, folders, glossaries, H5P activities, IMS packages,
labels, lessons, pages, quizzes, resources, SCORM packages, Video Time, wikis,
and workshops. Multi-document activities can send several documents with stable
source IDs.

The tenant identity is derived from the Moodle site URL, and the Privacy API
declares the external transfer of course/module metadata and extracted content.
The plugin does not index personal learner submissions where the bundled
extractors intentionally exclude them.

This version has been tested locally with Moodle 5.2.1, but the official plugin
metadata declares support for Moodle 4.5 to 5.1.
